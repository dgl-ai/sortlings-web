# sortlings-web

Build web (estático) del juego Sortlings (Godot). Publicado por Forge y servido en la URL sortlings dglabs cloud.

## Re-despliegue tras un push

En el VPS: bash tools/redeploy_web.sh (git pull + reinicio del servicio sortlings-web + verificación). Detalles en el vault: Infra/VPS/Servicios.md.
